# 🚀 Extrair SEO do YouTube - Manual de Uso

Bem-vindo ao **Extrair SEO do YouTube**, uma ferramenta profissional desenvolvida para ajudar criadores de conteúdo, agências de marketing e especialistas em SEO a analisar e copiar metadados estratégicos de qualquer vídeo do YouTube em poucos segundos.

Com este aplicativo, você consegue extrair de forma limpa: Miniaturas (Thumbnails), Títulos, Meta Descrições, Tags ocultas, Hashtags e Informações Gerais de engajamento do vídeo.

---

## 📂 Como Instalar e Rodar o Aplicativo

Este aplicativo foi distribuído em um formato portátil para sistemas **Windows**, o que significa que você não precisa instalar nenhuma linha de código ou abrir terminais complexos manualmente.

1. **Extraia o arquivo:** Se você recebeu este aplicativo em um arquivo compactado (`.zip`), clique com o botão direito nele e selecione **"Extrair Tudo"**.
2. **Abra a pasta:** Entre na pasta extraída chamada `Extrair_SEO_YouTube`.
3. **Execute o aplicativo:** Procure pelo arquivo executável **`Extrair_SEO_YouTube.exe`** (ele possui o ícone do terminal/aplicativo).
4. **Dê dois cliques:** Clique duas vezes sobre o arquivo `Extrair_SEO_YouTube.exe`.
5. **Aguarde a inicialização:** Uma tela preta de terminal se abrirá para carregar o servidor local interno. Em cerca de 3 a 5 segundos, uma aba no seu **navegador de internet padrão** se abrirá automaticamente com a interface visual do sistema.

> ⚠️ **Nota Importante:** Não feche a janela preta do terminal enquanto estiver usando o aplicativo. Se você fechar o terminal, o sistema sairá do ar. Quando terminar de usar, basta fechar o terminal que o aplicativo será encerrado com segurança.

---

## 🛠️ Como Utilizar a Ferramenta

A interface foi projetada para ser simples, intuitiva e extremamente rápida. Siga os passos abaixo:

1. **Insira o Link:** No campo indicado no topo da tela (*"Digite a URL do vídeo do YouTube"*), cole o link completo do vídeo que você deseja analisar (ex: `https://www.youtube.com/watch?v=...`).
2. **Buscar Dados:** Clique no botão verde **"Buscar Dados SEO"**. O sistema fará a leitura em tempo real diretamente dos servidores do YouTube.
3. **Download da Miniatura:** Se desejar salvar a imagem de capa do vídeo em alta resolução no seu computador, basta clicar no botão azul **"📥 Fazer Download da Miniatura"**.
4. **Copiar Campos Individuais:** Ao lado de cada caixa de texto (Título, Descrição, Tags, etc.), existe um botão azul **"📋 Copiar"**. Clique nele para enviar aquele texto específico instantaneamente para a sua área de transferência (*Ctrl + V*).
5. **Copiar Tudo Junto:** Caso queira economizar tempo e extrair todos os textos organizados de uma só vez, desça até o final da página e clique no botão laranja **"💥 Clique Aqui para Copiar Tudo Junto"**.
6. **Buscar Outro Vídeo:** Quando quiser limpar a tela para analisar um link diferente, clique no botão vermelho **"❌ Limpar Dados e Buscar Outro Vídeo"** no rodapé da página.

## ❓ Resolução de Problemas (FAQ)

### 1. Dei dois cliques no arquivo e o navegador não abriu automaticamente. O que eu faço?
Se o seu navegador não abrir sozinho, olhe para a janela preta do terminal. Lá haverá uma linha escrita algo como `Local URL: http://localhost:8501`. Basta copiar esse endereço `http://localhost:8501`, colar na barra de endereços do seu navegador (Chrome, Edge, Firefox) e apertar Enter.

### 2. O Windows exibiu um aviso de "Editor Desconhecido" ao abrir o programa. É seguro?
Sim, 100% seguro. Esse aviso acontece com qualquer aplicativo independente no formato `.exe` que não foi comprado ou registrado na loja oficial da Microsoft. Basta clicar em **"Mais informações"** e depois em **"Executar assim mesmo"** na primeira vez que abrir.
